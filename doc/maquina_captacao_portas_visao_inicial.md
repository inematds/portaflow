# Máquina de Captação — visão inicial

## Objetivo
Criar um sistema previsível que encontre pessoas e empresas com intenção de comprar portas internas brancas e entregue ao sistema de vendas apenas oportunidades relevantes.

## Arquitetura

### 1. Captura de demanda quente — prioridade máxima
Google Search para buscas como:
- porta interna branca
- kit porta pronta branca
- porta branca para quarto
- portas internas para obra
- orçamento portas internas
- fabricante / fornecedor de portas internas

Destino:
Google → página específica → WhatsApp / orçamento.

### 2. Geração de demanda
Meta / Instagram / Facebook com anúncios visuais:
- antes e depois;
- obra pronta;
- comparação porta tradicional x kit completo;
- erros ao comprar portas;
- demonstração de acabamento;
- cases e depoimentos.

Destino:
Anúncio → WhatsApp → qualificação automática.

### 3. Captação B2B
Criar uma frente específica para:
- arquitetos;
- construtores;
- engenheiros;
- empreiteiros;
- lojas/revendas.

Oferta diferente da pessoa física:
- orçamento por obra;
- tabela por volume;
- atendimento técnico;
- parceria recorrente.

### 4. Conteúdo orgânico
Criar conteúdos orientados a buscas e dúvidas reais:
- qual porta escolher;
- medidas;
- preço;
- instalação;
- tipos de acabamento;
- kit porta pronta;
- erros de obra.

Conteúdo → Google/Instagram/YouTube → WhatsApp.

### 5. Reativação
Usar a própria base:
- antigos leads;
- orçamentos não fechados;
- antigos clientes;
- arquitetos;
- construtores;
- indicações.

Campanhas automáticas de reativação e indicação.

## Hub central

Todas as fontes chegam em um único motor:

TRÁFEGO
↓
Landing page / WhatsApp
↓
IA de qualificação
↓
Pontuação do lead
↓
CRM
↓
Máquina de vendas

## Dados que devemos capturar
- origem;
- palavra-chave/campanha;
- cidade/CEP;
- perfil do comprador;
- quantidade de portas;
- fase da obra;
- prazo;
- medidas;
- orçamento;
- compra ou perda.

## Métrica principal

Não otimizar apenas para CPL.

Acompanhar:
Investimento → Leads → Leads qualificados → Orçamentos → Vendas → Receita → Margem

O objetivo é descobrir quanto custa gerar uma venda lucrativa por canal.

## MVP recomendado

Começar somente com:

1. Google Search
2. Landing page específica
3. WhatsApp
4. Qualificador automático
5. CRM
6. Rastreamento até a venda

Depois:
Meta Ads → remarketing → conteúdo → B2B → indicação.

## Princípio

A máquina de captação não deve procurar o maior número de leads.
Ela deve procurar repetidamente o perfil de cliente que mais fecha e gera margem.
