# 🚪 PortaFlow

**🇧🇷 [Português](README.md) · 🇺🇸 [English](README.en.md) · 🇪🇸 [Español](README.es.md)**

Máquina de ventas B2B de puertas interiores blancas por WhatsApp: el lead llega, la IA lo califica, un motor determinista calcula el presupuesto con el catálogo real, Pix cierra el pedido y Telegram avisa al dueño cuando se necesita atención humana.

## 📖 Guía de uso

Guía completa (landing + paso a paso): **https://inematds.github.io/portaflow/guia/es/**
