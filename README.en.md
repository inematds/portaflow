# 🚪 PortaFlow

**🇧🇷 [Português](README.md) · 🇺🇸 [English](README.en.md) · 🇪🇸 [Español](README.es.md)**

A B2B sales machine for white interior doors via WhatsApp: a lead comes in, AI qualifies it, a deterministic engine calculates the quote using the real catalog, Pix closes the order, and Telegram alerts the owner when a person needs to step in.

## 📖 User Guide

Complete guide (landing page + step-by-step instructions): **https://inematds.github.io/portaflow/guia/en/**
